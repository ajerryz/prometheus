# prometheus 可视化
1. prometheus 自带的表达式浏览器

表达式浏览器可在/graphPrometheus 服务器上使用，允许您输入任何表达式并在表格或随时间变化的图表中查看其结果。
主要用于临时查询和调试。


2. Grafana
- Grafana是一个开源分析和可视化平台，用于监控和分析来自各种数据源的指标。
- 允许用户创建、浏览和共享交互式仪表板，并支持与 Prometheus、InfluxDB、Elasticsearch 等数据库集成。
- Grafana 广泛用于可观察性，提供警报、插件可扩展性和灵活的查询编辑器，用于实时数据可视化。

3. Perses
- Perses是一个开源仪表板和可视化平台，专为可观察性而设计，原生支持 Prometheus 作为数据源。
- 它允许用户创建、管理和共享仪表板，用于监控指标和可视化数据。
- Perses 旨在提供一个简单、灵活且可扩展的仪表板替代方案，以替代其他仪表板工具，注重易用性、社区驱动的开发、GitOps 功能以及仪表板即代码的理念。

4. Console templates
- 控制台模板允许使用Go 模板语言创建任意控制台。这些由 Prometheus 服务器提供。
- 控制台模板是创建可在源代码管理中轻松管理的模板的最强大方法。不过，由于需要一定的学习曲线，因此初次接触此类监控的用户应该先尝试 Grafana。
